==============================================================================

【一、运行环境】
操作系统        : Windows-11-10.0.26200-SP0
Python 版本     : 3.14.5
NumPy 版本      : 2.4.6
scikit-learn 版本: 1.8.0
神经网络实现     : 纯 NumPy 手写 3 隐藏层 MLP（未使用 PyTorch / sklearn MLPClassifier）
matplotlib 字体  : Microsoft YaHei

【二、数据集】
来源            : sklearn.datasets.load_digits（随 scikit-learn 内置，无需联网下载）
定位            : MNIST 的迷你替代品——同样是 10 类手写数字，只是分辨率 8x8、规模 1797 张，
                  无法联网时用它复现同一结论，代价是细粒度笔画信息比 28x28 的 MNIST 少
样本总数        : 1797
图像尺寸        : 8 x 8 灰度，像素原始取值 0~16，输入时除以 16 归一化到 0~1
类别数          : 10（数字 0~9）
训练/测试划分   : test_size=0.25，stratify=y，random_state=42
训练集样本数    : 1347
测试集样本数    : 450
划分口径        : 与姊妹项目 handcrafted_vs_learned 使用同一 random_state=42，样本集合完全一致

【三、模型配置】
网络结构        : 64 -> 128(ReLU) -> 64(ReLU) -> 32(ReLU) -> 10(softmax)
         说明   : 输入 64 维像素 -> 3 个隐藏层（128, 64, 32）-> 10 类 softmax
激活函数        : 隐藏层 ReLU，输出层 softmax
损失函数        : 交叉熵（与 softmax 组合后梯度简化为 P - Y）
优化器          : Adam，学习率 0.001，L2 权重衰减 0.0001（只作用于权重）
训练轮数        : 300 个 epoch，batch_size = 64
参数总量        : 18986 个
随机种子        : 权重初始化 seed=42，样本打乱 seed=42

读法            : silhouette 越大越好（-1 ~ 1）；1-NN 留一越大越好；类内/类间越小越好。

【五之二、二维投影上重算的指标（也就是“图里肉眼看到的那个版本”）】
为什么单列：上面那张表算的是高维表示（64/128/32 维），而四宫格画的是压到 2 维之后的图。
            这里把两种投影各自重算一遍，用来证明“图上看到的团”和“高维数字的递进”是同一件事。
同类近邻率      : 在二维平面上离某个点最近的另一个点与它同色的比例——
                  颜色互相穿插时这个比例低，十类各抱一团时它接近 1，正是肉眼判断“成团”的依据。

| 表示        | PCA-2D silhouette | PCA-2D 同类近邻率 | t-SNE silhouette | t-SNE 同类近邻率 |
|-------------|-------------------|-------------------|------------------|------------------|
| input       |            0.1051 |            0.5871 |           0.5551 |           0.9878 |
| 1-st hidden |            0.1243 |            0.5910 |           0.6094 |           0.9917 |
| 2-nd hidden |            0.2074 |            0.6733 |           0.7251 |           0.9939 |
| 3-rd hidden |            0.2304 |            0.7062 |           0.7332 |           0.9955 |

PCA-2D 同类近邻率单调递进 : 是
    input 0.5871 → 1-st hidden 0.5910 → 2-nd hidden 0.6733 → 3-rd hidden 0.7062；逐层变化：1-st hidden +0.0039（变好），2-nd hidden +0.0824（变好），3-rd hidden +0.0328（变好）
t-SNE 同类近邻率单调递进  : 是
    input 0.9878 → 1-st hidden 0.9917 → 2-nd hidden 0.9939 → 3-rd hidden 0.9955；逐层变化：1-st hidden +0.0039（变好），2-nd hidden +0.0022（变好），3-rd hidden +0.0017（变好）

【七、递进性检查】
silhouette 单调递进 : 是
    input 0.1629 → 1-st hidden 0.2500 → 2-nd hidden 0.3735 → 3-rd hidden 0.4405；逐层变化：1-st hidden +0.0871（变好），2-nd hidden +0.1234（变好），3-rd hidden +0.0671（变好）
1-NN 留一单调递进  : 是
    input 0.9883 → 1-st hidden 0.9917 → 2-nd hidden 0.9955 → 3-rd hidden 0.9961；逐层变化：1-st hidden +0.0033（变好），2-nd hidden +0.0039（变好），3-rd hidden +0.0006（变好）
类内/类间单调下降   : 是
    input 0.8629 → 1-st hidden 0.6261 → 2-nd hidden 0.4295 → 3-rd hidden 0.3701；逐层变化：1-st hidden -0.2367（变好），2-nd hidden -0.1967（变好），3-rd hidden -0.0594（变好）

结论：高维表示的三类指标与两种二维投影上的同类近邻率全部随层数单调递进，
      「input 十类混杂 → 第 3 隐藏层十类各抱一团」在数字上和图上同时成立。
