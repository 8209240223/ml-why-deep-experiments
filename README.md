# 为什么"深"更好？——李宏毅《Why Deep》三个可复现教学实验

本仓库是李宏毅（Hung-yi Lee）机器学习课程《Why Deep / Why Deep Learning?》一讲的配套复现实验。
整讲有一条完整的论证链：**深网络更有效 → 靠模块化复用 → 靠逐层折叠空间 → 因此能用更少的数据学到更复杂的函数**。
下面三个子项目分别把这条链上的三个关键论点做成可运行、可复现、结果可量化的代码。

所有网络都是**纯 NumPy 手写**的（前向、反向、Adam 全部自己实现，不依赖 PyTorch / TensorFlow），
依赖只有 NumPy、matplotlib 和 scikit-learn。这样做的好处是每一步都可见，
梯度可以用有限差分校验，训练动态（平台期、逐层成团）能直接观察。

---

## 一、三个子项目一览

| 子项目 | 对应的 PPT 论点 | 回答的问题 | 核心结论 |
| --- | --- | --- | --- |
| `checkerboard_experiment/` | Folding the space / Use data effectively | 同样的训练预算下，深网络是不是更省数据？ | 2 万样本时 1 隐层网络完全没学动（0.4913），3 隐层保住了棋盘结构（0.9848） |
| `handcrafted_vs_learned/` | End-to-end Learning | 特征该人工设计，还是全部从数据里学？ | 端到端 97.56% 比人工特征 88.00% 高 9.56 个百分点，瓶颈在特征不在分类器 |
| `mnist_layerwise/` | 逐层成团（input → 1st → 2nd → 3rd hidden） | "越深越聚"是肉眼错觉还是能量化？ | 轮廓系数 0.1629 → 0.4405 逐层单调递进，且只看测试集时趋势一致 |

三个项目共用同一份数据划分口径（`random_state=42`），跨项目对比时不必再解释划分差异。

## 二、子项目一：`checkerboard_experiment/` —— 棋盘格深浅网络对照

**论点**：深网络通过多层变换把输入空间反复折叠，使原本高频复杂的边界变成容易分开的形式，
于是**用更少的数据**就能学到（PPT 第 21~23 页）。

**实验设计**：在 `[-1, 1]²` 正方形上均匀撒点，用下面这个函数打标签，得到一个转 45° 的菱形棋盘格二分类任务：

```
y(x1, x2) = ( floor((x1+x2)/s) + floor((x1-x2)/s) ) mod 2
```

这个任务的难点在于它同时需要 u 方向与 v 方向各一个周期结构，而且必须**组合**起来才成立，
单看任何一个方向都得不到标签——这就是它"高频、难学"的来源。

在同一个任务上跑 4 组配置（1 隐层 vs 3 隐层 × 10 万 vs 2 万样本），每个隐藏层 64 个 tanh 单元：

| 隐藏层数 | 训练样本 | 参数量 | 测试准确率（主协议） | 测试准确率（训练到收敛） |
| --- | --- | --- | --- | --- |
| 1 | 100000 | 257 | 0.9764 | 0.9834 |
| 1 | 20000 | 257 | **0.4913** | 0.9814 |
| 3 | 100000 | 8577 | 0.9805 | 0.9919 |
| 3 | 20000 | 8577 | **0.9848** | 0.9846 |

主协议（固定 200 轮 + 小批量 256）复现了 PPT 的现象：2 万样本时浅网络测试准确率 0.4913
（等于瞎猜，训练准确率也只有 0.4880，说明是停在损失 ln2 附近一步没走），
40 个棋盘格里有 18 个被整体判反；深网络则是 0.9848、0 个格子判反。

**这个项目最有价值的地方是它补了对照实验**：把训练次数给足（全批量、上限 2500 轮）之后，
1 隐层 × 2 万样本也能到 **0.9814**。也就是说浅网络的失败是**效率问题、不是能力问题**——
2 万样本时深网络用 3160 次更新就到 0.9578，浅网络用了 15800 次更新还在 0.49。
这与 PPT 第 18 页的普适性定理（一个隐藏层就能逼近任何连续函数）是一致的。

另外还有一个反直觉的事实：3 隐层的参数量是 1 隐层的 **33 倍**（8577 vs 257），
却在小数据上把对方甩开 49 个百分点——这正是参数**分层复用**（Modularization）的证据。

**产出**：`results/`（主协议）与 `results_converged/`（收敛协议）各含 4 张决策区域对比图、
2×2 汇总图、训练曲线、训练日志、指标 JSON，以及用 ASCII 字符渲染的决策区域
（`##` 表示预测红、`..` 表示预测蓝、`??` 表示模糊区），不打开图片也能核对结果。

## 三、子项目二：`handcrafted_vs_learned/` —— 人工特征 vs 端到端学习

**论点**：传统流水线用一个**人工设计、零可学习参数**的绿色模块把原始输入变成紧凑表示，
再交给一个可学习的分类器；端到端学习则把从特征到分类的每一个函数全部交给同一份数据、
同一个损失函数一起学出来（PPT 的 End-to-end Learning 两页）。

**实验设计**：用 scikit-learn 自带的 `load_digits`（1797 张 8×8 手写数字），
在同一份训练/测试划分上跑四条流水线：

| 方案 | 特征来源 | 分类器 | 输入维度 | 测试准确率 |
| --- | --- | --- | --- | --- |
| A1 | 人工：行投影 8 + 列投影 8 | 逻辑回归 | 16 | 88.00% |
| A2 | 人工：A1 + 象限均值 4 | 逻辑回归 | 20 | 88.67% |
| B | **无人工模块**，端到端学习 | NumPy 手写 MLP | 64 | **97.56%** |
| R | 无人工模块（参照组） | 逻辑回归（与 A 完全相同） | 64 | 96.22% |

**参照组 R 是设计上的关键**：它用的是和方案 A **一模一样**的逻辑回归，
唯一区别是输入端不做人工降维、直接吃 64 维像素。R 比 A2 高 7.56 个百分点，
分类器一个参数都没换——所以 9 个百分点里大约 7 个来自"人工特征丢了信息"，
只有 1 个多百分点才轮到"非线性模型比线性模型强"。**瓶颈在特征，不在分类器。**

信息是怎么丢的可以精确算出来：行投影 + 列投影拼成的 16×64 矩阵秩只有 **15**
（因为所有行投影之和恒等于所有列投影之和，都等于全图墨迹总和），
零空间维数 64−15 = **49**。加上 4 个象限均值后秩只升到 16、零空间只缩到 48 维——
这就是 A2 相对 A1 几乎没涨的根本原因。具体后果是 8 和 1 被大量混淆
（A2 对数字 8 的召回率只有 67.4%，端到端是 90.7%）：投影丢掉了"横向/纵向的相对位置"。

**产出**：`results/` 下 6 张 PNG（人工特征拆解、网络学出的第一层 64 个权重模板、
混淆矩阵对照、错分样本对照、特征空间 PCA 对比、训练曲线）与 `metrics.txt`。

## 四、子项目三：`mnist_layerwise/` —— 逐层表示聚类可视化

**论点**：深层网络的每一层都在做一次表示变换，浅层看到的是像素、深层看到的是语义。
网络逐层把"像素上像、语义上不像"的东西掰开，把"像素上不像、语义上一样"的东西拉到一起，
于是十个数字在深层各自抱成一团（PPT 的 MNIST 四宫格）。

**实验设计**：训练一个 3 隐藏层小网络（64 → 128 → 64 → 32 → 10，纯 NumPy，测试准确率 **98.44%**），
把同一批 1797 张样本分别放到 input / 1-st hidden / 2-nd hidden / 3-rd hidden 四种表示里，
各自降维到二维画散点，复刻 PPT 的四宫格。项目在这个骨架上补了三件事，
把它从"一张课堂示意图"变成"一个能复核的实验"：

1. 除 PCA 外再做一版 **t-SNE 对照**，排除"递进只是线性投影造成的错觉"；
2. 给每一层算**量化指标**：轮廓系数、1-NN 留一准确率、类内/类间比值；
3. 把指标拆成**全量 1797 张**与**只算测试集 450 张**两个口径，回答"团得紧会不会只是背下了训练样本"。

| 表示 | 维度 | 轮廓系数 | 1-NN 留一 | 类内/类间（越小越好） | PCA-2D 同类近邻率 |
| --- | --- | --- | --- | --- | --- |
| input | 64 | 0.1629 | 0.9883 | 0.8629 | 0.5871 |
| 1-st hidden | 128 | 0.2500 | 0.9917 | 0.6261 | 0.5910 |
| 2-nd hidden | 64 | 0.3735 | 0.9955 | 0.4295 | 0.6733 |
| 3-rd hidden | 32 | 0.4405 | 0.9961 | 0.3701 | 0.7062 |

四项指标全部逐层单调递进，而且**只看测试集的 450 张时趋势完全一致**
（轮廓系数 0.1631 → 0.4206）——说明逐层成团是学出来的表示性质，不是记忆。

最直观的读数是 PCA-2D 同类近邻率：在 input 面板上随便挑一个点，有超过四成的概率
它最近的邻居是别的数字；到第 3 隐藏层这个概率降到三成以下。

两个必须如实交代的观察：**t-SNE 版的对比强度明显弱于 PCA**（它的 input 面板上十类已经大致分开了，
因为 t-SNE 本来就只关心局部邻域，会把任何有局部结构的输入都拉成团），
所以它在这里只作为稳健性检查，要展示 PPT 那个论点必须用 PCA；
**跨层的绝对距离不可比**（ReLU 输出非负，层越深整体尺度越大，
第 3 隐藏层的类内平均距离反而是输入层的 3.6 倍），能跨层比较的只有比值和归一化过的量。

**产出**：`results/` 下 4 张 PNG（PCA 四宫格、t-SNE 四宫格、训练曲线、指标随层数变化）与 `metrics.txt`。

## 五、如何运行

### 5.1 环境要求

三个项目都只需要 **Python 3** + NumPy + matplotlib，third 项目还额外需要 scikit-learn。
两个手写数字项目用的是 `sklearn.datasets.load_digits`，**随库内置、不需要联网下载**。

```bash
python3 -c "import numpy, matplotlib, sklearn; print('ok')"
```

如果没有 scikit-learn：

```bash
pip install numpy matplotlib scikit-learn
```

（若系统 Python 是"外部管理"的发行版、`pip install` 被 PEP 668 拒绝，
请改用发行版自带的包管理器安装，例如 MSYS2 用 `pacman -S mingw-w64-ucrt-x86_64-python-scikit-learn`，
Debian / Ubuntu 用 `apt install python3-sklearn`。）

### 5.2 跑三个实验

```bash
# 子项目一：棋盘格（主协议，4 组配置，几分钟）
cd checkerboard_experiment
python3 checkerboard.py --outdir results --batch-size 256 --epochs 200 --lr 0.01 --lr-decay-epochs 100

# 想快速冒烟测试（几十秒，验证代码能跑通）
python3 checkerboard.py --samples 3000 1000 --layers 1 3 --epochs 400 \
    --test-size 2000 --resolution 100 --outdir /tmp/smoke

# 子项目二：人工特征 vs 端到端（十几秒）
cd ../handcrafted_vs_learned
python3 main.py

# 子项目三：逐层表示（约 30 秒，大头是四层 t-SNE）
cd ../mnist_layerwise
python3 main.py
```

三个脚本都会把图片和数值结果写进各自的 `results/` 目录，并在终端打印准确率对照。
所有随机性都通过显式传入的 `seed` / `random_state` 控制，
**同一条命令跑两次会得到完全相同的数字**。

### 5.3 常用参数

各项目的 README 里有完整参数表，这里只列最常用的几个：

| 项目 | 参数 | 作用 |
| --- | --- | --- |
| checkerboard | `--samples` / `--layers` | 训练样本量列表 / 隐藏层层数列表（做笛卡尔积） |
| checkerboard | `--batch-size 0` | 0 = 全批量梯度下降（对照协议用的就是这个） |
| checkerboard | `--init-scale` | 第一层权重初始化放大倍数，默认 4.0，是复现现象的关键超参 |
| handcrafted | `--hidden` / `--epochs` | 端到端网络的隐藏层宽度 / 训练轮数 |
| handcrafted | `--skip-extra-seeds` | 只跑主实验，跳过三个种子的稳定性检验，更快 |
| mnist_layerwise | `--seed` | 换种子复核递进现象是否稳健 |
| mnist_layerwise | `--epochs` | 训练轮数，默认 300 |

## 六、结果摘要

### 6.1 棋盘格实验：深网络在有限预算下更省数据

| 配置 | 主协议（200 轮 + 小批量） | 收敛协议（全批量 + 2500 轮上限） |
| --- | --- | --- |
| 1 隐层 × 10 万 | 0.9764（0/40 格子判反） | 0.9834（0/40） |
| 1 隐层 × 2 万 | **0.4913（18/40 格子判反）** | 0.9814（0/40） |
| 3 隐层 × 10 万 | 0.9805（0/40） | 0.9919（0/40） |
| 3 隐层 × 2 万 | **0.9848（0/40）** | 0.9846（0/40） |

结论有两条，必须一起看：主协议下**现象复现成功**（换随机种子 `--seed 1` 结论稳定，
浅网仍是 0.5088 / 18 个格子判反）；但收敛协议说明浅网络的失败是**效率**问题——
深网络用 3160 次更新到 0.9578 时，浅网络用了 15800 次更新还在 0.49，
原因是浅网络必须一次性拼出全部"山脊"，先要爬出一个很深的平台期。

### 6.2 人工特征 vs 端到端：瓶颈在特征

A1 88.00% / A2 88.67% / **B 97.56%** / R 96.22%。端到端比 A1 高 9.56 个百分点。
参照组 R（同一个逻辑回归，不做人工降维）拿到 96.22%，比 A2 高 7.56 个百分点——
差距的大头来自人工投影特征丢掉了空间位置信息（16×64 投影矩阵秩只有 15、零空间 49 维），
不是分类器太弱。三个随机种子下方案 B 都稳定领先。

### 6.3 逐层表示：四层指标全部单调递进

轮廓系数 0.1629 → 0.2500 → 0.3735 → 0.4405，1-NN 留一错误个数 21 → 15 → 8 → 7，
PCA-2D 同类近邻率 0.5871 → 0.7062，测试集单独看趋势一致（0.1631 → 0.4206）。
最深的机制解释是：**输出层只会切直线，逼着 h3 空间里十类线性可分，
而线性可分在距离结构上几乎必然表现为各自抱团**——团不是网络"想"聚出来的，
是被下游的线性要求逼出来的。

## 八、已知局限

- 手写数字类实验用的是 `load_digits`（8×8、1797 张），是 MNIST 的迷你版本。
  它的分辨率低、样本少，四宫格"混杂 → 成团"的程度比 28×28 MNIST 更夸张，
  绝对数值不能直接搬到 MNIST 上；本仓库没有运行真正的 MNIST。
- 棋盘格实验的 `results_converged/` 四组都跑满了 2500 轮上限，
  日志显示损失此时仍在缓慢下降，即"还没完全收敛，只是已经足够接近"。
- 逐层表示实验的隐藏层语义解释（第 1 层笔画 / 第 2 层部件 / 第 3 层整体）
  是从表示可分性与样本行为反推的定性描述，没有做神经元级可视化验证。
- t-SNE 的坐标没有物理含义，团与团之间的距离不可解释，相关结论只能定性使用。
- 各项目的运行耗时数字来自报告作者本机（Windows 11 + MSYS2 UCRT64），
  不同机器、不同 CPU 负载下会有波动；NumPy 矩阵乘法的多线程行为本身就会让耗时跳动。
