操作系统        : Windows-11-10.0.26200-SP0

NumPy 版本      : 2.4.6
scikit-learn 版本: 1.8.0
神经网络实现     : 纯 NumPy 手写 MLP（未使用 PyTorch，本机未安装）
matplotlib 字体  : Microsoft YaHei

【二、数据集】
来源            : sklearn.datasets.load_digits（随 scikit-learn 内置，无需联网下载）
样本总数        : 1797
图像尺寸        : 8 x 8 灰度，像素取值 0~16
类别数          : 10（数字 0~9）
每类样本数      : 178, 182, 177, 183, 181, 182, 181, 179, 174, 180

说明            : 两条流水线使用完全相同的划分（同一组样本下标），保证差距只来自特征来源

【三、方案配置】
方案 A（绿 + 蓝）: 人工特征提取器（固定公式、不可学习）+ 逻辑回归（唯一的学习模块）
                  A1 = 行投影 8 维 + 列投影 8 维 = 16 维
                  A2 = A1 + 4 个象限平均亮度 = 20 维
                  分类器：sklearn LogisticRegression(max_iter=5000, C=1.0, 默认 lbfgs)
方案 B（全蓝）   : 原始 64 维像素直接输入 MLP，无任何人工作用上的模块
                  网络结构：64 -> 64（ReLU）-> 10（softmax）
                  损失函数：交叉熵；优化器：Adam（mini-batch，batch_size=64，lr=0.001）
                  训练轮数：200 个 epoch

【四、主实验结果（测试集准确率对照）】
| 方案              | 后接模块     | 输入维度 | 测试准确率 | 百分比 |
|-------------------|--------------|----------|------------|--------|
| A1 人工特征 16 维 | + 逻辑回归   |       16 |     0.8800 | 88.00% |
| A2 人工特征 20 维 | + 逻辑回归   |       20 |     0.8867 | 88.67% |
| B  原始 64 维像素 | + 端到端 MLP |       64 |     0.9756 | 97.56% |
| R  原始 64 维像素 | + 逻辑回归   |       64 |     0.9622 | 96.22% |

方案 B 相对方案 A1 的准确率提升：9.56 个百分点
方案 B 相对方案 A2 的准确率提升：8.89 个百分点

关于参照组 R（它不属于 PPT 上的两种范式，只是实验层面的对照）：
  R 用的是与方案 A 一模一样的逻辑回归（同一个求解器、同一组超参数、同样是线性分类器），
  唯一区别是输入端不做人工降维。结果 R 相对 A2 变化了 +7.56 个百分点。
  这排除了「差距只是因为逻辑回归比神经网络弱」这一种解释，把原因锁定在人工特征本身的信息损失上。

【十、结论】
1. 端到端方案 B 的测试准确率 97.56%，明显高于人工投影特征方案 A1 的 88.00% 与 A2 的 88.67%。
2. 人工投影特征把 8x8 的空间结构压成「每行/每列有多少墨」，大量形状不同的数字在特征空间里重叠，这是方案 A1/A2 准确率上不去的根本原因；多补 4 个象限均值只能小幅改善，因为手工设计的分辨率始终有限。
3. 参照组 R（同一个逻辑回归，但输入换成未做人工降维的 64 维原始像素）拿到 96.22%，比方案 A1 高出 8.22 个百分点。分类器完全没变，唯一变的是特征，这直接证明瓶颈在人工特征而不是分类器能力。
4. 端到端方案的 64 个隐藏单元权重是梯度下降自己学出的 8x8 模板（见图 2），相当于用一整层「可以学的特征提取器」取代了人写死的投影公式，因此准确率最高。
